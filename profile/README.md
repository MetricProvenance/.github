# Metric Provenance

**Enterprise Compliance Enforcement & Verifiable Provenance for Data and AI** · [metricprovenance.com](https://www.metricprovenance.com/)

Metric Provenance builds deterministic compliance enforcement and cryptographic audit-trail infrastructure (`S-Cert`) for regulated enterprise data pipelines, AI systems, and European dataspaces — bridging policy definitions directly to runtime execution.

---

## Two-Track Architecture

1. **Enterprise Platform ([metricprovenance.com](https://www.metricprovenance.com/)):** Three-pillar enterprise suite (*Governance Hub · Integration Layer · Implementation & Assurance*) with air-gapped deployment options, domain chartering, and signed compliance evidence.
2. **Open-Source Protocol — ODGS `v6.1.0` (Apache 2.0):** Vendor-neutral runtime policy enforcement engine, normative JSON/LinkML schemas, and platform bridges published on [PyPI](https://pypi.org/project/odgs/) and [NPM](https://www.npmjs.com/package/odgs).

## Standards & Open-Source Ecosystem

- **Eclipse Foundation (`EMO #1466`):** Proposed open-source *Eclipse ODGS Dataspace Bridge* in public community review ([Proposal](https://projects.eclipse.org/proposals/eclipse-odgs-dataspace-bridge-runtime-compliance-enforcement-provenance)).
- **European Standardization:** Candidate specification *"Data management — Requirements for automated compliance enforcement and verifiable evidence in data transactions"* (`CEN/CLC JTC 25 N 380 Rev. 2`) under evaluation via **NEN (`NC 381 525`)** and **CEN/CLC JTC 25 / WG 2**.
